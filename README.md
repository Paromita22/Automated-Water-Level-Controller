# Automated-Water-Level-Controller
Automated Water Level Controller is a water level control system using IC555 to automate tank refilling and prevent water wastage. Ensured efficient water usage by automatically switching the motor off at high level and on at low level, reducing manual intervention and preventing overflow or dry runs.
